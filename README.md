## 🛠️ Flagship Systems & Receipts

### 1. Envision: Offline Edge-AI Smart Stick
* **Classification:** Patented Assistive Spatial Guidance System
* **Architecture:** Quantized edge YOLO computer vision model running on low-power silicon
* **Sensor Rig:** Dual ultrasonic spatial transducers + dynamic pulse-frequency haptic feedback
* **Receipts:** Granted patent architecture; physical field trials validated across partner disability NGOs in India

### 2. Sovereign Wearable AI Pendant
* **Compute:** Seeed Studio XIAO ESP32-C3 (32-bit RISC-V @ 160MHz, 400KB SRAM)
* **Audio Capture:** INMP441 omnidirectional digital microphone streaming direct to DMA over I2S
* **Storage:** MicroSD SPI buffer module for continuous local audio logging when offline
* **Power:** 3.7V 300mAh LiPo cell with battery management circuitry (< 15µA quiescent deep sleep)
* **Chassis:** Custom CAD enclosure 3D-printed on Anycubic Kobra 2 Neo (< 30g, 35x35x10mm)
* **BOM Target:** Strict sub-₹1,500 bill of materials breakdown

### 3. Vector Write: Kinematic Handwriting Synthesis
* **Machine Learning:** Recurrent Neural Network (RNN) continuous stroke generation model
* **Kinematics:** Direct conversion of synthesized handwriting trajectories into real-time Cartesian G-code
* **Plotter:** Custom 2-axis stepper plot bed with servo-controlled pen-lift pressure damping
* **Traction:** Autonomous commercial handwriting engine & proprietary stroke dataset

### 4. Zero-Dependency Python RAG Engine
* **Mission:** Systems engineering over framework bloat (*"Vibe coding sucks when something breaks"*)
* **Dependencies:** 100% pure Python standard library (`os`, `sys`, `urllib`, `math`, `json`)
* **Frameworks:** 0 LangChain, 0 ChromaDB, 0 LlamaIndex, 0 heavy packages
* **Pipeline:** Deterministic 350-word sliding window chunker + lexical keyword retriever with token overlap scoring
* **Footprint:** Runs in < 18MB RAM on 4GB machines and embedded Linux boards

### 5. Rubrica Platform

## 💻 Interactive Systems Console

The portfolio includes an in-browser interactive terminal allowing visitors to query hardware specs and pinouts directly:

| Command | Action |
| --- | --- |
| `help` | Display list of available inspection commands |
| `receipts` | View complete ledger of verified engineering receipts |
| `envision` | Print Envision smart stick patent & sensor specs |
| `wearable` | Print Sovereign pendant architecture & pinout |
| `vectorwrite` | Print RNN stroke synthesis & G-code kinematics |
| `rag` | Print zero-dependency Python RAG architecture |
| `bom` | Print sub-₹1,500 bill of materials breakdown |
| `bench` | Print physical hardware laboratory instrumentation |
| `contact` | Print direct wire coordinates & transmission channels |
| `clear` | Clear terminal output buffer |

## 🚀 Running Locally

Open `index.html` directly in any web browser, or serve locally:

```bash
# Using Python standard library
python -m http.server 8000

# Using Node
npx serve .
```

Visit `http://localhost:8000` to inspect the portfolio and test the interactive console.
